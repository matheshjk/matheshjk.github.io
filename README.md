## Projects

### 1. Experimental Investigation of Hammerhead Launcher Flows
Wind tunnel investigation of boattail radius effects in transonic flows using Schlieren and PIV.

Key findings:
• Larger boattail reduced separation by ~25%
• Increased shock-induced unsteadiness

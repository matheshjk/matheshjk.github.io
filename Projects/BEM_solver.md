# Blade Element Momentum (BEM) Solver

## Overview
This project implements a **Blade Element Momentum (BEM) solver** to predict the aerodynamic performance of a horizontal axis wind turbine (HAWT).

BEM theory combines **momentum theory** for the rotor control volume with **blade element aerodynamics** to estimate the forces generated by rotating blades. This approach provides an efficient method for predicting rotor thrust, torque and power without requiring high-fidelity CFD simulations.

The developed solver computes:

- axial and tangential induction factors  
- aerodynamic forces on blade elements  
- rotor thrust and torque  
- power coefficient and performance characteristics

---

# Blade Element Momentum Theory

## Methodology
In the BEM approach, the rotor is divided into a number of **annular blade elements** along the span. Each element is analysed independently by combining two aerodynamic models:

**Momentum theory**

The rotor is treated as an actuator disk that extracts momentum from the incoming flow. This provides relations for the **axial induction factor** and the resulting velocity deficit through the rotor.

**Blade element theory**

Each blade section is treated as a 2D airfoil producing lift and drag based on local flow conditions. Using airfoil aerodynamic data, the sectional forces can be computed.

By equating the forces predicted by these two models, the axial and tangential induction factors are obtained. The solution is found iteratively until convergence is reached for each blade element.

The resulting aerodynamic loads are integrated along the blade span to compute:

- rotor thrust  
- torque  
- power output

---

# Numerical Implementation

The solution procedure follows these main steps:

1. Discretise the rotor blade into spanwise elements  
2. Assume initial values for axial and tangential induction factors  
3. Compute local flow velocity and inflow angle  
4. Determine lift and drag forces using airfoil polar data  
5. Update induction factors using momentum relations  
6. Iterate until convergence for each blade element  
7. Integrate sectional loads to obtain overall rotor performance

This iterative approach allows the solver to capture the coupling between **blade aerodynamics and induced flow through the rotor disk**.

### Rotor Performance for Different Tip Speed Ratios

The BEM solver was used to evaluate rotor performance at different **tip speed ratios (TSR)**. The resulting thrust, torque and power coefficients are summarized below.

| TSR | C_T | C_Q | C_P |
|-----|-----|-----|-----|
| 6   | 0.490 | 0.060 | 0.363 |
| 8   | 0.656 | 0.056 | 0.447 |
| 10  | 0.765 | 0.046 | 0.457 |

These results demonstrate how BEM models can efficiently predict rotor performance and aerodynamic loading using simplified aerodynamic theory.

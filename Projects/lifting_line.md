# Frozen Wake Lifting Line Solver

## Overview
This project implements a **lifting line based aerodynamic solver** to analyse the performance of a horizontal axis wind turbine using a **frozen vortex wake model**.

Lifting line theory represents a finite wing or rotor blade using a spanwise distribution of **bound circulation**. The circulation along the blade generates **trailing vortices**, which form the rotor wake and induce additional velocities on the blades.

In this work, a numerical model was developed to compute the **circulation distribution along the rotor blade** while accounting for **wake-induced velocities** using a prescribed (frozen) vortex wake.

The solver predicts key rotor aerodynamic quantities such as:

- spanwise circulation distribution  
- induced velocity at the rotor plane  
- rotor thrust and power

---

# Lifting Line Formulation

## Methodology
The rotor blade is discretised into a number of **spanwise blade elements**, each represented by a bound vortex segment. According to lifting line theory, the aerodynamic loading is directly related to the **circulation distribution** along the blade.

Each blade element sheds a **trailing vortex filament** into the wake. These vortices induce velocities on the rotor blades, modifying the effective inflow velocity and therefore the local aerodynamic loading.

The induced velocity field is computed using the **Biot–Savart law**, which determines the velocity induced by each vortex filament.

In this model, the wake geometry is assumed to be **frozen**, meaning the shape of the wake is prescribed rather than dynamically evolved. This assumption simplifies the numerical model while still capturing the main aerodynamic interaction between the rotor and its wake.

The solution procedure consists of:

1. Discretising the rotor blade into spanwise elements  
2. Assigning bound circulation to each blade element  
3. Computing the induced velocity from trailing vortices  
4. Updating the circulation distribution based on the local flow conditions  
5. Iterating until the circulation distribution converges

---

# Wake Representation

The rotor wake is modelled using **helical vortex filaments** shed from each blade element. These trailing vortices represent the vorticity generated by the rotating blades and are responsible for the **induced velocity field** at the rotor plane.

The interaction between the **bound circulation on the blades** and the **trailing vortices in the wake** determines the final aerodynamic loading distribution.

Because the wake geometry is fixed (frozen wake assumption), the computational cost is significantly reduced compared to free wake simulations while still providing useful insight into rotor aerodynamics.
